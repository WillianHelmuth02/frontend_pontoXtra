# Relatórios

O ADM pode combinar nome do prestador, setor, status e período. Para isolar um dia, selecione a mesma data nos dois calendários. Os atalhos consultam hoje, os últimos sete dias, o mês até hoje ou todo o histórico.

Selecionar uma barra de setor, mês ou status filtra o painel inteiro. Indicadores e gráficos cobrem todas as páginas. O valor calculado soma as jornadas com cálculo no recorte. Selecione Pago para consultar quitações. O período se refere à data da jornada. A lista traz 50 itens por página e abre os detalhes para o administrador.

Operacional e RH usam a consulta pessoal com pesquisa e filtros. A API limita os registros ao criador autenticado e seleciona campos operacionais. Na página inicial do RH, as filas de trabalho usam contagens.
